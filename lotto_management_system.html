คู่มือการนำเว็บไซต์ขึ้น Vercel (Deployment Guide)

วิธีที่ 1: ใช้ Vercel Web Dashboard (ง่ายที่สุด ไม่ต้องใช้ Command Line)

1. บันทึกไฟล์หน้านี้เป็นชื่อ index.html
2. ไปที่เว็บไซต์ Vercel.com และสมัครสมาชิกฟรีด้วย GitHub หรือ Email
3. สร้าง Repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ index.html ไว้ที่ Root
4. บน Vercel กดปุ่ม Add New... -> Project แล้วเลือก Import Repository ของคุณ
5. กด Deploy ได้ทันทีโดยไม่ต้องตั้งค่า Build Command ใดๆ เพราะเป็น Static HTML เพียวๆ!

วิธีที่ 2: ใช้ Vercel CLI

1. ติดตั้ง Vercel CLI ในเครื่อง: npm i -g vercel
2. เปิด Terminal ในโฟลเดอร์ที่มีไฟล์นี้ แล้วพิมพ์คำสั่ง vercel
3. ทำตามขั้นตอนบนจอเพื่อเผยแพร่เว็บรับ URL ทันที
